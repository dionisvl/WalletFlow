## Зачем

Инструменты форензики рисуют красивые графы, но живут в облаке и не ведут учёт.
Налоговые сервисы ведут учёт, но без графа, и ты отдаёшь им всю карту своих кошельков.
WalletFlow посередине и хранит всё у тебя:

- **Всё локально.** Один бинарник, один файл SQLite. Без аккаунтов и телеметрии. Только публичные адреса, никаких seed-фраз и ключей.
- **Знает, что твоё.** Помечаешь адреса: *мой*, *биржа*, *чужой*, *наблюдаемый*. Переводы между своими кошельками и с биржами классифицируются сами.
- **Inbox zero.** Всё, что связано с чужими адресами, попадает в Inbox, который разбирается с клавиатуры (`1`…`9`, `j`/`k`). Одна галочка превращает выбор в правило на всю историю.
- **Видно, как движутся деньги.** Sankey: откуда пришло и куда ушло. Балансы во времени. Интерактивный граф связей.
- **Проверка связи кошельков.** Добавь 2–10 кошельков как *наблюдаемые*: граф покажет прямые переводы и **общих контрагентов**, даже если кошельки друг другу не платили.
- **Экспорт** полного журнала в Excel или CSV: имена, комиссии, ссылки.

## Попробовать за 10 секунд

Для демо ключи не нужны: вымышленные кошельки и 14 месяцев тестовых переводов.

```bash
go run github.com/dionisvl/walletflow/cmd/walletflow@latest -demo
```

Или скачай бинарник для macOS, Linux или Windows в [Releases](https://github.com/dionisvl/walletflow/releases) и запусти `walletflow -demo`.
Бинарники не подписаны: на macOS один раз выполни `xattr -d com.apple.quarantine walletflow`.
Язык интерфейса переключается внизу меню (English / Русский).

## Со своими кошельками

```bash
git clone https://github.com/dionisvl/walletflow && cd walletflow
cp .env.example .env      # бесплатный ключ Etherscan; TronGrid по желанию
go run ./cmd/walletflow   # откроется http://127.0.0.1:8080
```

1. **Кошельки**: адрес, имя и тип, или список.
2. **Синк**: скачивает историю (несколько адресов параллельно, с лимитами, продолжает с места остановки).
3. **Inbox**: разметка входящих и исходящих с чужими адресами.
4. **Потоки, Балансы, Граф, Экспорт**: результат.

Настройки описаны в [`.env.example`](.env.example). База лежит в папке настроек пользователя
(`~/Library/Application Support/WalletFlow` на macOS), флаг `-db` меняет путь.

## Типы адресов

| Тип | История скачивается | Что даёт |
|---|---|---|
| **Мой** | да | твой учёт: Inbox, балансы, потоки, экспорт. Мой ↔ мой = внутренний перевод |
| **Биржа** | нет | мой ↔ биржа распознаётся как депозит или вывод и не идёт в Inbox |
| **Чужой** | нет | просто имя контрагента. Переводы остаются в Inbox; авторазметка через правило |
| **Наблюдаемый** | да | чужой кошелёк, скачивается только для графа, в твой учёт не входит |
| *нет в книге* | нет | как «чужой», только без имени |

Адреса с одинаковым именем = одна сущность (все депозитные адреса Binance станут одним узлом).
У бирж сотни тысяч переводов, которые личному учёту не нужны: перед первым синком WalletFlow
оценивает активность адреса и пропускает его, если он похож на биржу или сервис.

## Сети

| Сеть | Источник | Заметки |
|---|---|---|
| Ethereum, Arbitrum, Polygon, Linea | Etherscan API V2 | один бесплатный ключ на все |
| Base, Optimism, BNB Chain | Etherscan API V2 | нужен платный тариф; скрываются через `IGNORE_CHAINS` |
| Tron (TRX, TRC20) | TronGrid | ключ необязателен |

## Приватность и безопасность

- Слушает `127.0.0.1` и отклоняет запросы с чужих сайтов (проверка Host и Origin).
- Обращается только к эксплорерам выше и только с публичными адресами.
- Предупреждает об address poisoning: похожие на твои адреса подсвечиваются в Inbox.
- Никогда не просит seed-фразы и ключи и не умеет переводить средства.
